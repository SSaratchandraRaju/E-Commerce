# 🛍️ E-Commerce Static Website

A modern, responsive **static e-commerce website** built using **HTML5, CSS3, and JavaScript**. This project showcases various pages essential for a basic online store, including product listings, cart, account management, and contact information.

---

## 🌐 Live Preview

🛍️ [**MyCart**](https://ssaratchandraraju.github.io/E-Commerce/)

---

## ✨ Features

* 🎨 Clean, modern UI design
* 📱 Fully responsive layout (desktop, tablet, mobile)
* 🛒 Product listing and cart pages
* 👤 Account and login placeholder pages
* 🗂️ Organized file structure for scalability
* ⚡ Fast loading and lightweight static site

## 🚀 Getting Started

### 🔧 Requirements

* Any modern web browser
* (Optional) Live Server extension for VS Code for real-time updates

### 🧑‍💻 How to Run Locally

1. Clone or download the project files
2. Open `index.html` directly in your browser
   OR run it using a live server for a smoother experience

```bash
git clone https://github.com/SSaratchandraRaju/E-Commerce
cd E-Commerce
# Then open index.html in your browser
```
